# Project memory

This directory explains the portfolio for future maintainers and AI coding agents. **Before modifying the project, read the relevant `/brain` files first.** Start with this file, then `01-PROJECT_BRIEF.md`, `04-ARCHITECTURE.md`, `05-CONTENT_MODEL.md`, and the document for the feature being changed.

After a meaningful change: read the existing architecture, change the implementation, update affected brain documents, and add a concise entry to `13-CHANGELOG.md`. Architecture or route changes must update `04-ARCHITECTURE.md`, `06-COMPONENT_MAP.md`, and `07-APP_MAP.md`. Content format changes must update `05-CONTENT_MODEL.md` and `09-EDITING_GUIDE.md`.

The public resume is the factual source. Do not infer employer dates, certificate links, project metrics, or social profiles from a design mockup.

`NEXT_CONTENT_AND_CASE_STUDIES.md` in the repository root tracks information still needed from Aagam and contains case study drafts. Treat its bracketed prompts as questions, not publishable facts.
